# 📊 Procurement Performance Dashboard (Delivery Date Basis)

## 🎯 วัตถุประสงค์ (Objective)

วิเคราะห์ประสิทธิภาพงานจัดซื้อและประเมินผลการดำเนินงานของซัพพลายเออร์ โดยอ้างอิงจากวันที่ส่งมอบสินค้าจริง (Delivery Date) เพื่อค้นหาโอกาสในการลดต้นทุน ควบคุมคุณภาพสินค้า และติดตามการปฏิบัติตามมาตรฐานของคู่ค้า

---

## 📋 รายละเอียดโครงการ (Project Description)

โครงการนี้นำข้อมูลการจัดซื้อจากชุดข้อมูล Procurement Dataset มาทำความสะอาดและเตรียมข้อมูลด้วย Python (Pandas) ก่อนนำไปวิเคราะห์และสร้างแดชบอร์ดแบบโต้ตอบด้วย Power BI

การวิเคราะห์ทั้งหมดอ้างอิงจากวันที่ส่งมอบสินค้าจริง (Delivery Date) แทนการใช้วันที่ออกใบสั่งซื้อ (PO Date) เพื่อสะท้อนผลการดำเนินงานที่เกิดขึ้นจริงของกระบวนการจัดซื้อและซัพพลายเออร์

---

## 👩‍💻 บทบาท (Role)

* ทำความสะอาดและแปลงข้อมูลด้วย Python (Pandas)
* จัดการข้อมูลที่ขาดหายและข้อมูลที่ไม่สอดคล้องกัน
* สร้างตัวชี้วัด (KPI) สำหรับการวิเคราะห์
* ออกแบบและพัฒนาแดชบอร์ดแบบโต้ตอบด้วย Power BI
* วิเคราะห์ข้อมูลและสรุปผลเชิงธุรกิจเพื่อสนับสนุนการตัดสินใจ

---

## ⚠️ ปัญหา (Problems)

* ข้อมูลคำสั่งซื้อบางรายการมีความไม่สอดคล้องกัน
* คุณภาพข้อมูลส่งผลต่อความถูกต้องของการวิเคราะห์

## 🛠 แนวทางแก้ไข (Solutions)

* ลบและปรับปรุงข้อมูลที่ไม่สมบูรณ์
* ปรับรูปแบบข้อมูลให้เป็นมาตรฐานด้วย Python (Pandas)
* เตรียมชุดข้อมูลให้พร้อมสำหรับการวิเคราะห์ใน Power BI
* สร้าง KPI สำหรับติดตามประสิทธิภาพการจัดซื้อและซัพพลายเออร์

## 📊 ภาพรวมแดชบอร์ด (Dashboard Overview)

แดชบอร์ดนี้ถูกออกแบบมาเพื่อติดตามประสิทธิภาพงานจัดซื้อผ่าน 4 มุมมองหลัก

### 1. การบริหารต้นทุนและการประหยัด (Cost Savings Performance)

* Total Savings (YTD)
* Savings %
* Total Savings by Supplier
* Total Savings by Delivery Date

ใช้วิเคราะห์มูลค่าการประหยัดต้นทุนและเปรียบเทียบผลงานของซัพพลายเออร์แต่ละราย

### 2. การควบคุมคุณภาพสินค้า (Product Quality Monitoring)

* Defect Rate %
* Defect Rate by Delivery Date
* Defect Rate by Item Category

ใช้ติดตามอัตราสินค้าชำรุดและระบุหมวดหมู่สินค้าที่มีปัญหาด้านคุณภาพ

### 3. ประสิทธิภาพกระบวนการจัดซื้อ (Procurement Efficiency)

* Average Lead Time

ใช้วัดระยะเวลาเฉลี่ยตั้งแต่เริ่มสั่งซื้อจนถึงวันที่ได้รับสินค้า เพื่อประเมินประสิทธิภาพการจัดส่งของซัพพลายเออร์

### 4. การปฏิบัติตามมาตรฐาน (Supplier Compliance)

* Compliance Status Distribution

ใช้ตรวจสอบว่าสินค้าและการส่งมอบเป็นไปตามข้อกำหนดและเงื่อนไขที่กำหนดไว้หรือไม่

## 📈 ผลลัพธ์จากการวิเคราะห์ (Key Findings)

### การประหยัดต้นทุน (Cost Savings)

* สามารถสร้างมูลค่าการประหยัดต้นทุนรวมได้ประมาณ 2.93 ล้าน
* ค่าเฉลี่ยการประหยัดจากการต่อรองราคาอยู่ที่ 7.82% สะท้อนถึงประสิทธิภาพของกระบวนการจัดซื้อ

### การควบคุมคุณภาพสินค้า (Quality Analysis)

* หมวด Office Supplies และ Raw Materials มีอัตราสินค้าชำรุดสูงที่สุด
* หมวด Packaging และ MRO มีอัตราสินค้าชำรุดต่ำกว่า 6.5% แสดงถึงการควบคุมคุณภาพที่ดีกว่า

### การปฏิบัติตามมาตรฐาน (Compliance)

* ประมาณ 84% ของรายการจัดซื้อเป็นไปตามมาตรฐานและข้อกำหนดที่กำหนดไว้
* การรักษาระดับ Compliance ที่สูงช่วยเพิ่มความน่าเชื่อถือของซัพพลายเออร์

### การมีส่วนร่วมของซัพพลายเออร์ (Supplier Contribution)

* Beta_Supplies และ Epsilon_Group เป็นซัพพลายเออร์ที่สร้างมูลค่าการประหยัดต้นทุนได้สูงที่สุด
* สามารถนำผลลัพธ์ไปใช้ในการกำหนดกลยุทธ์ Preferred Supplier ได้

### แนวโน้มการประหยัดต้นทุน (Savings Trend)

* การประหยัดต้นทุนมีความผันผวนตลอดช่วงเวลาการวิเคราะห์
* พบจุดสูงสุดในช่วงไตรมาสที่ 2 ของปี 2023 ซึ่งสามารถนำไปใช้วางแผนการเจรจาต่อรองและการจัดซื้อในอนาคตได้
